# SIFA Global Institute — Website V1

This is a first professional static website for SIFA Global Institute.

## Run it on your computer
1. Extract this ZIP.
2. Open the folder.
3. Double-click `index.html`.
4. The website will open in your browser.
5. Use the navigation to test every page.

No programming installation is required for this first version.

## Important
- Replace/add real social-media URLs only after they are confirmed.
- The application form currently prepares an email through the visitor's email client.
- Certificate verification is a planned feature and is intentionally not presented as an active database.
- Scholarships are described as potential/conditional opportunities, not as currently open programs.
- Before public launch, review all course availability, legal/organizational status, privacy information, and contact details.

## Main pages
Home, About, Founder, Courses, Learning, Certification, Resources, Scholarships, Verify, Contact, Apply.
